# Privacy Policy for LinkedIn Connection Booster

*Last updated: November 2026*

Thank you for using **LinkedIn Connection Booster** — a browser extension designed to simplify LinkedIn connection invitation and profile-following activities.

Your privacy is important to us. This Privacy Policy explains how **LinkedIn Connection Booster** handles user data and protects your information while using the extension.

---

## 1. Introduction

LinkedIn Connection Booster (“the Extension”) is developed and maintained by [Amit Das](https://amitdas.site) under **Blue Orbit Devs**.

This Privacy Policy explains how the Extension handles user data while you use the extension available on the Chrome Web Store.

By installing or using LinkedIn Connection Booster, you agree to the practices described below.

---

## 2. Data Collection

LinkedIn Connection Booster is designed to minimize data collection.

The Extension may access relevant LinkedIn page content, such as profile information and connection-related page elements, solely to provide its core functionality.

The Extension does not intentionally collect or transmit LinkedIn passwords, private messages, or unrelated browsing data to the developer.

LinkedIn profile information and connection activity are processed within the browser for the Extension's intended functionality.

We do not sell, rent, or trade user data.

---

## 3. Data Storage

LinkedIn Connection Booster uses the **Chrome `storage` API** to store the following information locally on your device:

* Basic extension settings and user preferences
* Activity counters and related extension state
* Pro license activation status and related license information

The Extension does not intentionally store LinkedIn passwords or private message content.

Local extension data is stored within your Chrome browser and is not shared with the developer's servers for unrelated purposes.

---

## 4. Permissions Explanation

### a. `scripting`

Used to execute the Extension's functionality on relevant LinkedIn pages. This permission allows the Extension to interact with page elements required for connection invitation and profile-following workflows.

### b. `activeTab`

Used to access the currently active browser tab when the user interacts with the Extension. This helps the Extension perform its intended functionality on the LinkedIn page selected by the user.

### c. `storage`

Used to store extension settings, activity counters, and license-related information locally in the browser.

### d. `tabs`

Used to identify and access the relevant LinkedIn browser tab required for the Extension's functionality.

The Extension does not use this permission to collect unrelated browsing history.

### e. `host_permissions`

The Extension requests access to the following websites:

```text
https://www.linkedin.com/*
https://api.gumroad.com/*
```

**LinkedIn Host Permission**

This permission is required solely to enable connection invitation and profile-following functionality on LinkedIn pages.

**Gumroad Host Permission**

This permission is required to communicate with the Gumroad API for Pro license verification and activation.

The Extension does not intentionally access unrelated websites.

---

## 5. Third-Party Services

LinkedIn Connection Booster uses Gumroad's API for Pro license verification and activation.

Gumroad is a third-party service that may process information submitted during license verification according to its own privacy policy.

The Extension does not use Gumroad for collecting unrelated LinkedIn account information.

### 5.1 Gumroad License Verification

Gumroad API requests may include the license key and other information required to validate the license.

* License information is used solely for Pro license verification and activation.
* Payment card details are not collected directly by the Extension.
* License verification information is transmitted to Gumroad when required.
* We do not use license information for advertising or analytics.

Gumroad Privacy Policy:

https://gumroad.com/privacy

---

## 6. Data Security

LinkedIn Connection Booster is designed to handle information only as necessary for its intended functionality.

We take reasonable measures to protect information handled by the Extension.

Users are encouraged to:

* Keep their Chrome browser updated.
* Install the Extension only from trusted sources.
* Keep their license keys private.
* Use the Extension responsibly.

No software or electronic transmission can be guaranteed to be completely secure.

---

## 7. User Control

Users can manage their extension data at any time by:

1. Removing LinkedIn Connection Booster from Chrome.
2. Clearing extension storage through Chrome browser settings.
3. Stopping extension activities using the available controls.

Removing the Extension may delete locally stored preferences, activity counters, and license-related information.

Users remain in control of their LinkedIn accounts and can manage their LinkedIn account settings independently.
