## 🧩 Overview

**LinkedIn Connection Booster** is a simple and intuitive Chrome extension designed to streamline your LinkedIn networking workflow.

Manage connection invitation activities and profile-following workflows through a clean, minimal interface. Monitor activity with a built-in counter and use convenient controls to manage your workflow.

Whether you're a professional, recruiter, freelancer, entrepreneur, or business owner, LinkedIn Connection Booster helps make your networking activities more convenient and organized.

### 🧭 Manual Installation Steps

1. Download the extension source code or ZIP file from GitHub Releases.
2. Extract the downloaded ZIP file.
3. Open `chrome://extensions/` in your Chrome browser.
4. Enable **Developer Mode** in the top-right corner.
5. Click **Load unpacked**.
6. Select the extracted extension folder containing `manifest.json`.
7. LinkedIn Connection Booster will be installed. ✅

## 🔒 Privacy & Security

LinkedIn Connection Booster is designed to minimize unnecessary data handling.

- The Extension does not request your LinkedIn password directly.
- Extension settings and activity counters may be stored locally.
- Gumroad API is used for Pro license verification.
- Permissions are intended to support the Extension's core functionality.
- No unrelated advertising or analytics functionality is intended.

Read our full [Privacy Policy](PRIVACY.md).

---

## 🧰 Permissions Used

| Permission | Purpose |
|---|---|
| `scripting` | Executes the Extension's functionality on relevant LinkedIn pages. |
| `activeTab` | Accesses the currently active tab when the user interacts with the Extension. |
| `storage` | Stores extension settings, activity counters, and license-related status. |
| `tabs` | Identifies the relevant browser tab for extension functionality. |

### Host Permissions

```text
https://www.linkedin.com/*
https://api.gumroad.com/*
```

- **LinkedIn:** Required to provide connection invitation and profile-following functionality on LinkedIn pages.
- **Gumroad API:** Required for Pro license verification and activation.
